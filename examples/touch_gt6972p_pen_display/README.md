# GT6972P 主动笔屏幕测试

该示例在逻辑分辨率为 540x960 的竖屏墨水屏上显示 GT6972P 主动笔状态，并提供可书写的测试画布。GT6972P 触摸传感器的分辨率为 684x1216，程序会把完整触摸区域线性映射到完整屏幕区域。

显示内容包括：

- 原始坐标和映射后的屏幕坐标
- 悬停、接触和橡皮擦状态
- 压感及对应线宽
- X/Y 倾角和方向指示
- 两个侧键、橡皮擦、电量、事件频率和错误计数
- 固件 PID、I2C 地址、触摸分辨率和屏幕分辨率

主动笔悬停时显示十字光标，落笔后留下轨迹，橡皮擦状态使用白色粗线擦除。短按 BOOT 清空画布，长按 BOOT 一秒执行全屏质量刷新。

触摸采样运行在独立任务中。墨水屏刷新期间采集的笔点会进入 256 点队列，刷新完成后仍按采样顺序连接，因此显示速度低于触摸采样速度时不会把连续笔画切成点段。接触书写期间暂停状态栏刷新，只使用 `epd_fastest` 刷新笔迹区域；抬笔后再执行质量清理和状态更新。

触摸引脚与 `examples/touch` 相同：SDA 39、SCL 40、INT 3、RST 9。坐标映射固定使用 684x1216，不采用 IC 信息中可能与屏幕配置一致的 960x540 范围。坐标方向可通过 `main/main.ino` 顶部的 `kSwapAxes`、`kInvertX` 和 `kInvertY` 调整。

```text
pio run -e T5_E_PAPER_S3_V7
pio run -e T5_E_PAPER_S3_V7 -t upload
pio device monitor -b 115200
```
